# Trang web mod Dime

## Đưa lên GitHub Pages
1. Vào github.com, bấm New repository, đặt tên (ví dụ `dime-mod`), chọn Public.
2. Bấm "uploading an existing file", kéo thả `index.html` và thư mục `assets` vào, rồi Commit.
3. Vào Settings -> Pages -> Source: Deploy from a branch, chọn `main` và `/ (root)`, bấm Save.
4. Vài phút sau trang chạy tại `https://TEN_CUA_BAN.github.io/dime-mod/`.

## Cho mọi người tải mod
1. Trong repo, bấm Releases -> Create a new release.
2. Đặt tag (ví dụ `v1.0.0`), kéo file `.jar` của mod vào, bấm Publish release.
3. Nút "Tải mod" trên trang sẽ trỏ tới release mới nhất.

## Sửa thông tin
Mở `index.html`, tìm đoạn `CONFIG` ở cuối file, đổi `github` thành link repo của bạn (và phiên bản nếu cần).
